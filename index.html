Local-first 3D print tooling

TokenForge Generator

A local Python/NiceGUI app for turning your own images into thin 2.5D embossed STL token packages for single-nozzle, manual-filament-swap 3D printing.

Install locally

This generator runs on your computer. GitHub Pages can host this landing page, but it cannot run the Python/NiceGUI app itself.

git clone https://github.com/QuantumPickleJar/tokenforge-generator.git
cd tokenforge-generator
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .[dev]
tokenforge-local

What it creates

  • 2.5D STL token model
  • Preview images
  • Manual filament swap plan
  • Print notes and project JSON

What it does not do

  • No slicing or G-code generation
  • No cloud image generation requirement
  • No AMS requirement
  • No copyrighted asset downloader
